# HDI_SavePrintSettings

A 4D v16 **HDI** (How Do I) binary database demonstrating "New commands to save and restore print settings", converted to a 4D project using 4D 21. The codebase was then updated and cleaned up with the help of **GitHub Copilot**.

## Origin

This project started as a binary `.4DB` example database originally distributed with 4D {version}. It was converted to the modern project architecture (`.4DProject`) using 4D 21's built-in binary-to-project conversion tool.

- **Blog post:** https://blog.4d.com/web-server-in-preemptive-mode/

- **Original download:** https://download.4d.com/Demos/4D_v16/HDI_WebServerPreemptive.zip
